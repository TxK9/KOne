# Historical acceptance record: Knine 0.1.17 personal edition

This record describes the earlier 0.1.17-selfuse / build-18 delivery. It is not a fresh acceptance result for the current tree.

The recorded in-place installation retained the existing signing identity, application data, UID, and first-install metadata. The dashboard added a small detected exit-address value below the profile name. Failed detection, disconnect, profile changes, and mode changes hide stale results without a pending placeholder. Detection uses only the VPN network owned by the application and does not obtain a fallback result through a direct network.

The record states that eight unrelated Tools source changes were reverted. Earlier category, dark-background transparency, bright-background reading surfaces, and node-selection behavior were included. Connection flow, core, configuration, traffic calculation, and the connected status area retained their corresponding baseline.

Recorded checks: 79 base tests, eight native tests, signed release packaging, and release lint passed. Compose/Robolectric rendering used synthetic sample data and reserved example addresses.

Device limits: installation and version were checked, but no active Knine VPN service was observed. No connection was started and no screenshot was taken for this delivery, so the actual exit address was not tested. A previously observed competing-VPN issue was not reproduced during this run; no competing application was installed or controlled.
