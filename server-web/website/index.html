Installation

Android

Download the APK and follow Android’s installation prompts. Enter your key in KOne, then approve the VPN permission when connecting for the first time.

Windows

Choose x64 for Intel / AMD, or ARM64 for ARM / Snapdragon. Install the MSI, then import your nodes. Use a claim link for managed access.
