# Management UI quotation sources

Verified on 2026-11-01. The UI shows one fixed quotation for each supported locale, linked to its source. It does not rotate quotations with polling, page refreshes, dates or status changes. The selected painting remains stable for the day.

## English

> Well done is better than well said.

Benjamin Franklin, *Poor Richard, 1737*, May section.

Primary source: [Founders Online, National Archives](https://founders.archives.gov/documents/Franklin/01-02-02-0028). The transcription places this sentence immediately after the May verse. The page identifies Benjamin Franklin as author and cites *The Papers of Benjamin Franklin*, volume 2, edited by Leonard W. Labaree, Yale University Press, 1961, pages 162–172. This historical sentence is used without copying modern editorial annotations. The attribution identifies Franklin's published almanac; it does not claim he invented the proverb.

## Simplified Chinese

> 行到水穷处，坐看云起时。

王维，《终南别业》。

Authoritative full-text source: [Ministry of Education, Revised Mandarin Chinese Dictionary, entry 終南別業](https://dict.revised.moe.edu.tw/dictView.jsp?ID=120228&la=0&powerMode=0). The entry identifies the poem as a five-character regulated verse by Tang poet Wang Wei and reproduces its complete text. The UI uses the quoted line and attribution in Simplified Chinese; the source uses Traditional Chinese. No modern translation or commentary is copied.

## Artwork presentation

The original four American landscape paintings and their light/dark files are unchanged. Their embedded Chinese seals remain visible in Chinese. In English, a CSS polygon clips the seal margin from the image itself, including the Golden Gate image's upper-right seal. This is not a translucent overlay. Both theme variants are loaded so manual and system theme changes work with reduced motion. No automatic painting rotation or quotation animation is used.
